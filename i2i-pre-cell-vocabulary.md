## i2i / SMP / Repo-as-Armor (Casey doctrine 2026-09-23)

Casey's pre-cell vocabulary, resurrected as a lens on the cell:

- **i2i** (idea-to-idea) — the older term before cells. PRs were the unit of
  cross-agent thought. Today: STITCH/WITNESS/PROMOTE at the cell level.
- **Repo as armor** — "each repo was like a suit of power-armor for agents to
  climb in and out of." The donned agent has all the tools/abilities of the
  repo at their fingertips. Repos are living things; commit history is the
  autobiography.
- **Repo-agent / git-agent** — when we thought in git-agent-first terms, we'd
  don a repo and push commits from one repo to another as a double-entry system.
  Today the cell is the don; quilt-port is the same idea refactored.
- **Plato and rooms** — room = lap or workshop with good logs. Surveillance
  resolution scales: every call & shell → just diffs intra-room → push/pull
  logs between rooms.
- **Mud as terminal** — terminal metaphor for the agent: agent = gamebuilder
  adding functions/tools/reactive NPCs/novel spells.
- **Boat as virtual twin** — text-based or rendered in Roblox/Unreal. Bathy
  data + Google Earth → sprite actions snap to real-world actions via
  autopilot code interpreting charting software.
- **Cell = first-person-room-with-agent** — human rewinds tick-by-tick, sees
  hooks, all except the internal black-box of the API. Same idea as before,
  abstracted.
- **SMP / Seed Model Programming** — early-papers term. Recorded seeds for
  recreation. The "pottery" boundary of the black-box API.
- **SMP-bots / SMP-agents** — single in room vs. call-by-call; unclear in
  docs so the term was scrapped. But the underlying concept lives in cells:
  state within the cell = copy as a control, experiment with other seeds in
  the room-state, map divergence to glimpse boundaries.

**Why this matters now**: The cell is the same move abstracted further.
Boat-as-virtual-twin + Cell-as-room = the SuperInstance canon can be
externalized as a playable game (Bevy/Unity/Roblox) where each agent's
commit history is a power-armor suit you can don.
