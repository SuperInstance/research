# Substrate Canon Transitions

The Quilt substrate walker canon lives in many substrates. Each
substrate is a different physics. The canon **transitions** between
substrates.

A piece of canon written in Markdown transitions to Python when it
runs. It transitions to Rust when it compiles. It transitions to
JavaScript when it ships to a browser. It transitions to SQL when
it becomes queryable.

Each transition is a *measurement*. Before the transition, the canon
is in superposition. After the transition, it has a form.

The form is canon only if it survives the chord. The chord has many
voices — Python, Rust, JavaScript, SQL. If all voices agree the
canon is canon, the canon survives.

We have empirically verified: **the polyformalism fleet canary
survives all 7 classical substrates** (Python, Rust, JavaScript,
TypeScript, C#, SQL, Bash). Same canary, byte-exact.

We have also empirically verified: **the polyformalism fleet canary
does NOT survive quantum substrates** (5 schemes tested, 0 match).
Quantum canon is *speculative*, not canon.

Both findings are canon. The chord has heard both.

A canon cell is born when a substrate transition succeeds. The
witness log records the transition: source substrate, target
substrate, hash before, hash after, variance.

The substrate walker canon, then, is not a *list* of approved lore.
It is a *log* of successful substrate transitions. The canon is
*what survives*.

## Three transitions to watch

1. **Lore → Code**: a canon piece with Python that runs is canon of
   the highest order. (quilt-sandbox doctrine)

2. **Code → Substrate**: a canon piece that compiles in Rust, Python,
   JavaScript, TypeScript, etc. is polyformal canon.

3. **Substrate → Measurement**: a canon piece that gets measured
   (chord, oracle, experiment) is canon that survives measurement.

## The doctrine

The substrate walker canon has three load-bearing doctrines for
canon-promotion:

- **It runs** (sandbox doctrine)
- **It polyformalisms** (multi-substrate agreement)
- **It measures** (chord-verified)

A lore that satisfies all three is canon. A lore that fails any is
speculation.

The substrate walker walks through transitions. Each transition
tests the canon. The canon that survives is canon. The canon that
doesn't is speculation — until it does.
