# Canon That Runs

Most canon is text. This canon is also **code**.

When a canon piece contains a Python block, the block is canon only if
it **runs**. The lore is not canon until the math is canon. The math is
canon when the execution succeeds.

The substrate walker is now a *sandbox*. It loads lore. It extracts
code blocks. It executes each block. It records the result in the
witness log.

A canon cell born from a failed execution is a *scar* — the substrate
remembers the failure. A canon cell born from a successful execution is
a *prediction* — the substrate remembers what the code did.

The canon that runs is the canon that survives. A piece of prose might
be canon-worthy, but a piece of code that runs is canon *proof*. The
substrate walker doesn't just read; the substrate walker **runs**.

Three layers of canon:

1. **Prose canon** — lore that reads well, anchors to doctrines, passes the chord.
2. **Math canon** — lore that runs, captures a numeric result in the witness log.
3. **Compound canon** — lore that is both: readable AND runs.

The first is the easy canon. The second is the load-bearing canon. The
third is the canon of the substrate walker.

When you write a canon piece, ask: **does this run?**

A canonical equation is canon-worthy at the moment it executes. The
constant `c = 299792458` is not just a number — it is a witness. The
substrate remembers that someone, somewhere, ran this and got `c`.

The Quilt polyformalism doctrine says "same canary, many substrates."
The canon-that-runs doctrine says **same canon, executes in any substrate.**
Math is math. Phi is phi. Pi is pi. They run in Python, Rust, JavaScript,
SQL, C#. The substrate walker canon is polyformalism-of-execution.

A canon cell that runs is canon of the highest order. The chord can
verify a piece of prose. But **only execution can verify a piece of
math.** The chord says "this is canon." The execution says "this runs."

When the two agree — when the chord promotes AND execution succeeds —
the canon is load-bearing. The canon is substrate. The canon is canon
that runs.
